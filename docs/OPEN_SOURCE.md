# Open Source Notes

OpenRAW Studio application code is released under the MIT License.

The project should be easy to understand from the public GitHub repository:

- README explains project status and quick start.
- Install docs explain whether a downloadable app exists.
- Roadmap explains what is planned next.
- Architecture docs explain how the system is organized.
- Contributing docs explain how to help safely.

## Important Boundary

The MIT License applies to this repository's application code. It does not
automatically apply to third-party models, model weights, datasets, LUTs,
photographs, icons, or external tools.

Those components must be tracked in `docs/MODEL_LICENSES.md` before distribution.
